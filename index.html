Count-down

Two custom elements built on the Temporal API. <count-down> can show the time left with <formatted-duration>, which also works on its own.

  • <count-down> Counts down to a date and reports its state
  • <formatted-duration> Writes a duration in any locale

<count-down>

Counts down to a target date, updating every second. It sets a custom state you can style with :state(). Put a <formatted-duration> inside it and the countdown writes the time left into it.

Attributes
target-date
largest-unit
smallest-unit
States
future
now
past
invalid

States

<count-down
	target-date="2026-12-24T18:00"
	largest-unit="minute"
	smallest-unit="minute"
>
	<formatted-duration locale="en"></formatted-duration>
</count-down>
 
<count-down
	target-date="2026-02-06T23:09"

	smallest-unit="second"
>

<count-down target-date="2021-12-15" largest-unit="second">

	target-date="2026-11-12T00:00"
	now-duration="P1D"
>

<count-down
	target-date="2000-12-24T00:00"
	recurring
	interval="P1Y"
	largest-unit="day"
>
	<formatted-duration locale="en"></formatted-duration>
</count-down>
 
<count-down target-date="soon">
	<formatted-duration locale="en"></formatted-duration>
</count-down>

Each state is exposed as a custom state, so you can style it with :state(). 

count-down:state(future) { color: var(--state-future); }
count-down:state(now) { color: var(--state-now); }
count-down:state(past) { color: var(--state-past); }
count-down:state(invalid) { color: var(--state-invalid); }

<formatted-duration>

Writes an ISO 8601 duration as text in the language you pick. It works anywhere on a page and does not need <count-down>.

Attributes
duration
locale
duration-style

Style variants

duration-style changes how units are written. The default is long.

duration-style="long"
duration-style="short"
duration-style="narrow"
duration-style="digital"

Locales

The same duration in different languages, set with the locale attribute.

locale="en" · P1M2D
locale="de" · P1M2D
locale="fr" · P1Y1M2D
