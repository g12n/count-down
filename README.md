# \<Count-down\>

A modern countdown html custom element utilizing [Temporal API].

This repository is work in progress.

**Browser Support:** Baseline Newly available features are fine. Temporal is
used natively where available and loaded from a polyfill (with Subresource
Integrity) otherwise, e.g. in Safari.


[Temporal API]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal

https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal/Duration#iso_8601_duration_format

https://en.wikipedia.org/wiki/ISO_8601#Durations

## System Overview
Two custom elements with no build step. `<count-down>` computes the time left
until a target date and `<formatted-duration>` writes a duration as localized
text. `<count-down>` writes the remaining time into a nested
`<formatted-duration>` through its `duration` attribute; `<formatted-duration>`
also works on its own. `index.html` is the demo page: it defines both elements
from `./src/formatted-duration/define.js` and `./src/count-down/define.js`
and styles them with `styles.css`, including the `:state()` rules for `<count-down>`.

## Subdirectories & System Boundaries
- src/count-down: [./src/count-down/README.md](./src/count-down/README.md) - `<count-down>`
  element: target date, units, status states, one-second tick.
- src/formatted-duration: [./src/formatted-duration/README.md](./src/formatted-duration/README.md) -
  `<formatted-duration>` element: ISO duration to localized text.

## Install and import
Each component has a class module and a `define.js` that registers the tag:

```js
import "@g12n/time/count-down/define"; // registers <count-down>
import { CountdownElement } from "@g12n/time/count-down"; // class only
```

Install from git: `npm i github:g12n/count-down#v0.1.0`. `custom-elements.json`
(generated by `npm run cem`, committed) describes both elements. Release with
`npm run release:patch|minor|major`; pushing the `v*` tag deploys `index.html`
to GitHub Pages.

## Global Invariants
- `Temporal` must be defined before either element module is imported. `index.html`
  loads the polyfill first when `typeof Temporal === "undefined"`, then imports both
  modules.
- Both elements are configured only through plain attributes (`target-date`,
  `largest-unit`, `smallest-unit`; `duration`, `locale`, `duration-style`). Their
  only coupling is the `duration` attribute `<count-down>` sets on its
  `<formatted-duration>` child.
- The modules must be loaded over HTTP (ES module imports), not from `file://`.

## Global Side Effects
- `index.html` fetches `temporal-polyfill@0.3.0` (`global.min.js`, with SRI) from
  `cdn.jsdelivr.net` when `Temporal` is missing.
- `index.html` loads `html-demo.js` from `nudeui.com`, which loads Prism from
  `prismjs.com`, for the demo code blocks.
- `<count-down>` runs a 1000 ms interval while connected; `<formatted-duration>`
  rewrites its own children on each render.

## System Verification
- No automated tests. Serve the repo root (e.g. `python3 -m http.server`) and open
  `index.html`.
